NGÀY 3: TẠO BACKEND RESTFUL API VỚI JAVA SPRING BOOT & CẤU HÌNH CORS
--------------------------------------------------------------------------------
* Mục tiêu: Dựng thành công Backend cung cấp API CRUD chuẩn RESTful và mở CORS.
* Kiến thức trọng tâm:
  1. Entity & Repository: Cấu hình Spring Data JPA kết nối DB (SQL Server / MySQL).
  2. Controller Annotations: `@RestController`, `@RequestMapping("/api/v1/products")`.
  3. HTTP Methods:
     - `@GetMapping`: Lấy danh sách hoặc 1 chi tiết.
     - `@PostMapping`: Tạo mới dữ liệu.
     - `@PutMapping("/{id}")`: Cập nhật dữ liệu.
     - `@DeleteMapping("/{id}")`: Xóa dữ liệu.
  4. `@CrossOrigin`: Cho phép React (port 5173 / 3000) gọi API vào Spring Boot (port 8080).
* Thực hành:
  - Tạo Spring Boot project với các dependency: Web, JPA, Lombok, Driver DB.
  - Viết Entity `Product` (id, name, price, status, category).
  - Viết các endpoint CRUD hoàn chỉnh.
  - THÊM ANNOTATION: `@CrossOrigin(origins = "*")` trên Controller class.

NGÀY 4: TÍCH HỢP READ & CREATE (GET & POST API VỚI AXIOS)
--------------------------------------------------------------------------------
* Mục tiêu: Kết nối React với Spring Boot để tải danh sách và gửi form tạo mới dữ liệu.
* Kiến thức trọng tâm:
  1. Thư viện Axios: `npm install axios`
  2. `useEffect` Hook: Tự động chạy code khi Component mount (chỉ định dependencies `[]`).
  3. Luồng kết nối GET:
     `useEffect` -> `axios.get(URL)` -> nhận dữ liệu -> `setData()` -> render `.map()`.
  4. Luồng kết nối POST:
     Submit form -> `axios.post(URL, formData)` -> thành công -> gọi lại hàm lấy danh sách (reload data).
* Thực hành:
  - Tạo file `api.js` cấu hình base Axios instance (baseURL: `http://localhost:8080/api`).
  - Gọi API GET hiển thị danh sách sản phẩm lên bảng HTML/React.
  - Gửi data từ Form React lên API POST để lưu vào database.

III. 3 QUY TẮC VÀNG VÀ SỰ CỐ THƯỜNG GẶP TRONG BÀI THI PE

1. LỖI CORS (Cross-Origin Resource Sharing)
   - Triệu chứng: Console trình duyệt báo lỗi màu đỏ dạng "Access-Control-Allow-Origin".
   - Khắc phục: Kiểm tra ngay Controller trong Spring Boot đã có `@CrossOrigin("*")` hay chưa.

2. TRẠNG THÁI KHÔNG ĐỒNG BỘ GIAO DIỆN (UI STALE DATA)
   - Triệu chứng: Thêm/Sửa/Xóa thành công ở database nhưng màn hình React không đổi.
   - Khắc phục: Sau khi gọi API POST/PUT/DELETE thành công trong khối `.then()` 
     hoặc sau `await`, luôn luôn gọi lại hàm `fetchData()` để lấy danh sách mới nhất.

--- 1. SPRING BOOT CONTROLLER PATTERN ---
@RestController
@RequestMapping("/api/v1/products")
@CrossOrigin(origins = "*")
public class ProductController {
    @Autowired
    private ProductRepository repo;

    @GetMapping
    public List<Product> getAll() {
        return repo.findAll();
    }

    @PostMapping
    public Product create(@RequestBody Product product) {
        return repo.save(product);
    }

    @PutMapping("/{id}")
    public Product update(@PathVariable Long id, @RequestBody Product product) {
        product.setId(id);
        return repo.save(product);
    }

    @DeleteMapping("/{id}")
    public void delete(@PathVariable Long id) {
        repo.deleteById(id);
    }
}

--- 2. REACT AXIOS FETCH & RENDER PATTERN ---
import React, { useState, useEffect } from 'react';
import axios from 'axios';

function ProductList() {
    const [products, setProducts] = useState([]);

    const loadProducts = async () => {
        try {
            const res = await axios.get('http://localhost:8080/api/v1/products');
            setProducts(res.data);
        } catch (error) {
            console.error("Lỗi khi tải dữ liệu:", error);
        }
    };

    useEffect(() => {
        loadProducts();
    }, []);

    const handleDelete = async (id) => {
        if (window.confirm("Bạn có chắc chắn muốn xóa?")) {
            await axios.delete(`http://localhost:8080/api/v1/products/${id}`);
            loadProducts(); // Load lại danh sách sau khi xóa
        }
    };

    return (
        <div>
            <h2>Danh sách sản phẩm</h2>
            <table>
                <thead>
                    <tr><th>ID</th><th>Tên</th><th>Giá</th><th>Hành động</th></tr>
                </thead>
                <tbody>
                    {products.map(item => (
                        <tr key={item.id}>
                            <td>{item.id}</td>
                            <td>{item.name}</td>
                            <td>{item.price}</td>
                            <td>
                                <button onClick={() => handleDelete(item.id)}>Xóa</button>
                            </td>
                        </tr>
                    ))}
                </tbody>
            </table>
        </div>
    );
}

export default ProductList;
